## H2 5 — Intégrer un template dans son projet (workflow) (≈ 200 mots)

### H3 5.1 — Installation et personnalisation
- Cloner, installer, configurer `.env`.
- Renommer la marque, couleurs, logo.
- Adapter le schéma Prisma.

### H3 5.2 — Ajouter sa logique métier
- Où mettre les features spécifiques.
- Conserver la structure `app/`, `components/`, `lib/`.
- Ne pas modifier le core auth/paiement sans raison.

### H3 5.3 — Connecter son API IA (NeuraAPI)
- Brancher `/api/ai/*` dans le template.
- Exemple : dashboard avec génération de rapport IA.

### H3 5.4 — Déploiement et mise en production

## FAQ (≈ 180 mots)

**Q1 : Un template premium vaut-il vraiment le coup pour un solo founder ?**
R : Oui, le ROI est immédiat si le template couvre auth + paiement + UI.

**Q2 : Peut-on utiliser un template commercial pour un client ?**
R : Vérifier la licence (souvent illimitée pour projets clients, pas de revente du template).

**Q3 : Les templates sont-ils compatibles Next.js 15 ?**
R : Vérifier la version ; NeuraAPI templates sont sur Next.js 14 avec migration documentée.

**Q4 : Faut-il tout personnaliser ou garder la structure ?**
R : Personnaliser la marque et les features, garder le core.

**Q5 : Un template remplace-t-il un développeur ?**
R : Non, il accélère le setup ; la logique métier reste à coder.
